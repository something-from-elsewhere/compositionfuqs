## A unique type system? What that?
compositionfuqs uses a type system i refer to as "composite typing". in essence, one binding may refer to any number of types, and each is a unique value + representation. bindings may be "projected"
with the `->` operator in order to be seen as any one `type`, or as any `[composition, of, types]`.
## Okay, how build?
make sure you have rust + cargo, and then `cargo build`. easy. rust makes things simple :3
## Why make this
at first because i wanted a unique programming language for my upcoming video game composite->knowledge, but this eventually became its own project. now i make it because i think the idea of an esolang
that doesn't suck to program in is pretty cool actually.
